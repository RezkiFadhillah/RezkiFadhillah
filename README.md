#### 1️⃣ Competitive Intelligence Agent (NL2SQL) 🤖
*Sistem cerdas pengolah data industri gaming yang tidak terstruktur.*
- **Tech Stack:** Llama 3.3 (Groq), LlamaParse, ChromaDB, FastAPI, Streamlit.
- **Fitur:** Transformasi PDF laporan industri menjadi database SQL terstruktur. Mendukung query bahasa alami (Natural Language to SQL) dengan pola *Two-Step Reasoning*.
- **Impact:** Memungkinkan stakeholder melakukan eksplorasi data kompleks tanpa perlu kemampuan SQL.

#### 2️⃣ Fabric Classification System (Thesis Project) 🧶
*Klasifikasi jenis kain berbasis citra digital dengan optimasi tinggi.*
- **Tech Stack:** Python, SVM, Particle Swarm Optimization (PSO), OpenCV.
- **Fitur:** Ekstraksi fitur Warna (HSV) & Tekstur (GLCM). Optimasi seleksi fitur menggunakan PSO.
- **Impact:** Mencapai akurasi **91.18%** pada pengujian multiclass (Jersey, Katun, Polyester).

#### 3️⃣ Bank Transaction Analyzer (Hybrid ML) 🏦
*Segmentasi nasabah dan klasifikasi transaksi otomatis.*
- **Tech Stack:** Scikit-Learn, K-Means, Random Forest, PCA.
- **Workflow:** Menggabungkan Unsupervised Learning (Clustering) untuk labeling data dan Supervised Learning untuk prediksi kategori transaksi masa depan.
